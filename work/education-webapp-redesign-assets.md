소스 검색 결과 JSX 이미지 import, CSS `background-image` 사진·일러스트, `srcset`, preload, 외부 이미지 URL은 없습니다. 기존 `TopicBadge`의 CSS 패턴은 정보 구조용 장식이며 일반 이미지 자산이 아니므로 생성 대상에서 제외했습니다.

## 이미지 생성 결정

`imagegen`은 실행하지 않았습니다. 이번 리디자인에서 안전하게 생성하거나 교체할 수 있는 일반 교육용 시각 자산이 없고, 유일한 SVG는 브랜드 식별 자산이어서 자동 대체가 금지되기 때문입니다. 이미지 생성 결과를 추가하지 않는 것이 설계 문서의 중립 주제·가벼운 정적 앱·자산 안전 범위와 일치합니다.

## 롤백

이 리디자인에서 자산을 수정하지 않았으므로 롤백은 `public/favicon.svg`의 기존 참조를 유지하는 것입니다. 자산 관련 변경이 발견되면 해당 파일만 원래 커밋 버전으로 복구하고 JSX·CSS에 새 외부 URL을 남기지 않습니다.

## 검증 경계

- 자산 HTTP 상태와 상대 경로는 최종 브라우저 검증에서 확인합니다.
- 이 기록은 실제 사용자 아동 관찰, VoiceOver 승인, 저작권 승인 또는 배포 증거를 의미하지 않습니다.
- 생성·교체 없는 결정은 최종 리디자인 보고서에 `imagegen not run`으로 재기록합니다.
