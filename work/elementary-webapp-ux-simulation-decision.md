# Elementary Web App Simulation Decision

판정일: 2026-08-31
판정: `not-needed`
대상: 추천 알고리즘 균형 실험실의 기존 DOM 기반 결정적 실험

## 결정 근거

- 학습 목표는 선택→추천 분포 변화→탐색→균형 설정 비교→공급 조건 감사이며, 이미 각 단계가 native button/radio/slider와 표로 구현되어 있습니다.
- 학생은 카드 선택 전에 다음 목록 변화를 예측하고, 선택 뒤 전후 카드 수를 관찰하고, 틀린 비교 답을 수정하며, 세 설정과 두 공급 조건을 근거로 보고서를 완성합니다.
- 결과는 8장 고정·정수 카드 수·결정적 규칙으로 계산되며 `RESET`이 초기 상태를 재현합니다. 시간에 따른 자동 진행이 없어 pause/step은 적용 대상이 아닙니다.
- Canvas/WebGL, 외부 데이터, 실제 플랫폼 측정, 확률·성능 주장이 없어 2D/3D 게임형 시뮬레이션이나 새 시각화 런타임을 추가할 학습 근거가 없습니다.
- 모바일·reduced-motion fallback과 DOM 표가 이미 결과를 정적으로 읽게 하므로 새 시뮬레이션 의존성은 안전·개인정보 경계를 넓힙니다.

## 기존 루프 검증

| 루프 | 현재 증거 | 판정 |
| --- | --- | --- |
| 예측 | `다음 목록 예측`에서 두 방향 선택 | 통과 |
| 조작 | 같은 카드 3회, 탐색 카드 1회, 다양성 슬라이더·관심 기록 라디오 | 통과 |
| 관찰 | 전후 분포 표, 카드 수 요약, 공급 감사 표 | 통과 |
| 설명 | 보고서 목적·요인·지표·한계 선택과 완료 문장 | 통과 |
| 재시도/reset | 비교 오답 수정, 감사 오답 수정, 빈 보고서 focus, `새 실험 시작` reset | 통과 |
| reduced-motion | pulse/transition 정지와 정적 안내 | 통과 |

## 구현 범위

새 시뮬레이션은 구현하지 않습니다. 이번 개선은 기존 결정표의 읽기 부담을 줄이고, 같은 DOM 루프의 핵심 행동 cue와 용어 설명을 보완하는 presentation-layer 작업으로 제한합니다.
